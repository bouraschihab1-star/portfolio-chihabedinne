SAÉ — Conception d'un multimètre

Résumé

SAÉ sur 3 jours : concevoir un multimètre fonctionnel pour mesurer courants, résistances et tensions.

  • Théorie : Automatisme (Karnaugh), électronique (pont diviseur). Routage Tinkercad.
  • Pratique : Soudure composants sur CI + tests.
  • Programmation : Programme Arduino — calibres auto, LEDs, affichage 7 segments.

Bilan : mise en pratique des compétences du S1 sur un cas concret.

AC11.01 : Analyse fonctionnelle — découpage multimètre.

AC11.02 : Prototype — soudure + programme Arduino.

SAÉ — Régulateur de température

Objectif

Régulateur de température en binôme, 2 semaines — 8 fonctions, 7 cartes pastillées modulaires.

  • Init : Carte Alimenter+Capter à deux. Schémas papier avant soudure.
  • Autonomie : 3 cartes chacun. Mes fonctions : Commande Chauffe, Chauffer, Clignoter.
  • Process : Théorie → schéma → montage réel → soudure optimisée.
  • Tests : Banc d'essai par carte. Inspection, correction, validation.

AC11.01 : Décomposition fonctionnelle.

AC11.02 : Schémas, prototypes, soudure plaque pastillée.

AC11.03 : Rédaction compte-rendu.

AC12.01 : Procédure d'essai stricte après chaque étape.
